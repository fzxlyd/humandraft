# HumanDraft 中文说明

HumanDraft 是一个开源写作审稿工具，不是又一个“AI 自动写作工具”。

它解决的问题很直接：很多 AI 生成文本看起来完整，读起来却很假。常见表现包括：

- 开头假悬念：`你绝对想不到`
- 空话套话：`在这个快节奏的时代`
- 没有证据的权威口吻：`科学研究表明`
- 人物像工具人，行为没有常识
- 情绪被说出来，而不是被动作表现出来
- 结论跳得太快，因果链断掉

HumanDraft 的第一版先做“审稿”，不急着做“生成”。它会把文本里的问题指出来，并给出可执行的改写方向。

## 适合谁用

- 用 AI 写文章、脚本、短视频文案，但不信任输出质量的人
- 内容团队的编辑
- 需要事实依据的科普/研究型内容作者
- 想建立自己写作规则库的创作者

## 快速使用

```bash
git clone https://github.com/fzxlyd/humandraft.git
cd humandraft
npm test
node src/cli.mjs audit samples/qiba-ai-ish.md --profile qiba
```

## 当前能检查什么

- AI 腔套话
- 假悬念
- 没有证据的权威表达
- 居高临下的说教语气
- 抽象词过多、具体动作不足
- 针对 `qiba` 这类食物科普短视频脚本的证据风险

## 项目方向

长期目标不是做一个“帮你一键生成爆款”的工具，而是做一个写作工作台：

1. 资料层：先有证据，再写结论。
2. 记忆层：记住人物、场景、世界规则、前文因果。
3. 审稿层：多个审稿器分别检查 AI 腔、事实、常识、结构、声音。
4. 改写层：每次改写都必须回应具体审稿意见。
